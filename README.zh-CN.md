尖塔铸卡是一款面向 **《杀戮尖塔 1》** 的 Windows 工具。用自然语言设计新卡，检查规则与生成的实现，通过手动编辑或 AI 再修改完善效果，并实时加入游戏。原生卡牌、本局卡组及后续奖励／商店牌池编辑也集成在同一工具中。

项目原名 STSCardEditor。已有数据目录及内部 `stseditor` 标识保持兼容。

## 核心功能

- **AI 创作与再修改**：描述效果、触发条件、衍生卡与升级行为；不满意时基于原卡继续修改。
- **两种创作路径**：结构化效果适合已支持机制；自由 Java 设计经过规则清单、编译、行为探针与一致性检查。
- **结果可编辑**：调整数值、属性、名称与描述；对照修改草稿，保留原卡 ID 保存。
- **实时游戏工具**：地图或允许的战斗状态下增删、升级本局卡牌；管理卡组预设和未来奖励／商店牌池。
- **四职业支持**：战士、猎手、机器人、观者共 300 张原生卡，提供基础／升级描述、职业筛选与多选。
- **中英文界面**：右上角 **语言 / Language** 即时切换，保留未保存输入和选择，重启后记住语言。

界面语言不改变游戏语言，也不会自动翻译用户的卡名、描述与提示词。原生卡另有英文目录与描述。

## 开始使用

1. 从 [Releases](https://github.com/SENECA-wendy/spireforge-ai/releases) 下载并完整解压便携包。EXE 必须与 `tools`、`sdk`、卡牌目录及 `data` 放在一起。
2. 在安装了 .NET Framework 4.8 的 Windows 10/11 上运行 **SpireForgeAI-v1.7.0.exe**，选择自己的 Steam《杀戮尖塔 1》目录。
3. **首次安装或升级适配层**时退出游戏，在编辑器内执行安装／应用，工具会创建备份。之后从 Steam 正常选择 **“玩 Slay the Spire”**。
4. AI 创作需配置模型服务的兼容 API 地址、模型名与 Key。自由 Java 设计另需 JDK，建议 JDK 17，可通过 `JAVA_HOME` 检测。离线解析仅支持有限的结构化效果，主要面向中文提示词。
5. 创建并检查卡牌，同步定义，然后加入本局牌组或可获得牌池。

示例：

> 设计一张猎手技能牌“备用刀片”，费用 1。向手牌加入恰好 3 张临时的 0 费攻击牌，每张造成 4 点伤害并消耗。升级后母卡生成 4 张。描述必须与实际数量一致。

模型服务可能按请求收费；一次生成可能包含多轮规划、校验和修复。软件不附带 API Key 或付费模型订阅。保存 Key 时使用 Windows DPAPI 加密。

## 实时修改的边界

| 操作 | 生效方式 |
| --- | --- |
| 原生卡数值 | 同步受支持的字段到游戏实例；特殊原生机制可能自行重新计算，请阅读机制说明。 |
| 本局牌组 | 地图与允许的战斗安全时机可用；过渡动画或选牌界面可能排队或拒绝请求。 |
| 新自定义卡 | 已安装适配层支持所需机制时，可不退出游戏同步新定义。 |
| 替换已加载 Java 扩展 | 相同 ID 的扩展加载后，更换代码可能需要重启游戏。 |
| 奖励／商店牌池 | 影响之后生成的卡牌，不重置已显示的商店或奖励。只留一张卡时可能重复出现。 |
| 只修改描述 | 仅改变文字；实际效果需要修改参数或重新生成实现。 |

自由设计不等于无限改写游戏引擎：尚未提供的生命周期钩子需要继续开发适配层。编译与行为探针通过不能证明所有实战组合都正确，生成后仍应审阅并实战验证。目前复用游戏现有卡图，不支持图片导入。

适配层通过本地启动包装器与补丁类工作，不依赖 ModTheSpire / BaseMod，但会修改本地安装；Steam 验证文件可能覆盖它。保留 Steam 初始化与成就调用路径，但**尚未独立实测解锁一个此前未解锁的新成就，不保证成就一定正常**。可通过“恢复原版”恢复启动文件。涉及存档中的自定义卡或扩展时，请保留存档备份，避免删除后无法继续原来的局。

## 源码构建

需要 Windows、PowerShell 7、.NET Framework 4.8 编译器、JDK 17 和本地正版游戏。仓库不包含游戏本体二进制或美术资源。

```powershell
pwsh .\build-portable.ps1 -GameDir "D:\Steam\steamapps\common\SlayTheSpire" -Jdk "C:\Java\jdk-17"
```

脚本会校验／下载 ASM 9.7.1，编译程序与适配层，从本机游戏提取中英文卡牌目录，生成 `dist/SpireForgeAI-v1.7.0-portable.zip`。构建本身不会把补丁安装到游戏。编辑器 **1.7.0**，适配层 **1.6.0**。

完整构建后，仅修改界面可运行 `pwsh .\build-editor.ps1`。翻译修改：编辑 `localization/en.json`，运行 `py -3 tools/prepare-localization.py` 后重新编译；不要使用历史迁移参数 `--initialize`。

构建后运行隔离测试：

```powershell
pwsh .\tests\run.ps1 -Jdk "C:\Java\jdk-17" -GameJar "D:\Steam\steamapps\common\SlayTheSpire\desktop-1.0.jar"
```

已安装适配层时传入 `desktop-1.0-original.jar`。本地测试通过 **309 项检查**，含 21 项语言切换与状态保留检查；这不等同于真实模型联调或完整游戏实战。

## 代码目录

- `app/`：WinForms 界面、模型接口、校验、卡库与实时编辑。
- `src/java/`：启动包装器、字节码补丁、运行时与扩展钩子。
- `localization/`：英文界面字典，中文为源语言。
- `tools/catalog-probe-src/`：从本机游戏提取原生卡目录。
- `tools/creative-probe-src/`：隔离的生成卡行为探针。
- `sdk/`：扩展示例与构建助手。
- `tests/`：回归检查与测试替身。
